# 可靠性与安全设计检查

涉及相应风险时读取，按当前系统应用。这里是决策检查项，不是让每个设计增加所有组件；不能用“安全”或“可靠”替代具体边界和失败语义。

## 数据与隐私

- 先确认数据是否真的需要收集、可否减少精度/留存时间、谁可以访问及如何删除。不要默认每个 PII 字段都要“加密列 + 哈希列”
- 业务必须恢复原值时再设计加密存储，说明密钥与数据分离、访问控制、轮换和恢复责任；传输保护、日志脱敏、备份与导出也属于泄露边界
- 仅在确有等值检索/去重需要时考虑带密钥的 HMAC 等索引，说明规范化方式、密钥保护、轮换和唯一约束。手机号等低熵数据不能靠普通 SHA-256 防枚举；HMAC 也不是匿名化，会暴露相等关系，不应随意共享
- 密码使用成熟的带盐自适应密码哈希方案（例如 Argon2id，具体参数结合环境确定），不使用可逆加密或普通快速哈希。会话令牌、访问密钥不能写入普通日志
- 金额注明货币、精度和舍入规则，可采用定点整数或适当的 decimal；持续时间、时间戳、设备测量等注明单位与时区/时钟语义
- 数据模型列出真正影响契约的唯一性、可空性、状态值及合法迁移，关键索引依据查询模式；不能把未知枚举值当成已完整设计
- 缓存或键值存储只在需要时使用。设计键的隔离范围、过期/失效和容量处理；不将明文 PII 或秘密放进键名。可持久键不必强行 TTL，但必须解释生命周期与清理责任

## 身份、会话与权限

- 根据应用选择现有 SSO/OIDC、服务端会话、签名令牌或其他合适机制，不限定“JWT 二选一”。认证成功不代表有对象访问权，多租户/对象级授权应在可信边界执行
- JWT 只是一种令牌格式。短期 access token 的本地验签可以无状态；refresh token 轮换、重用检测、会话管理或撤销通常仍依赖服务端状态，不能把整个系统描述成“完全无状态”
- 说明登出、封禁、权限变化何时生效，以及已签发 access token 的剩余有效期如何处理。若要求立即吊销，需在线状态检查或其他满足要求的机制，并纳入可用性和延迟设计
- 根据实际客户端和传输方式设计令牌存放、防泄露及必要的 CSRF/XSS 控制，不机械套用某种浏览器方案到桌面/设备
- 不在文档里填真实密钥、凭据或生产令牌。法规、认证等级和数据地域约束以已确认来源为准，不把使用某个组件等同于合规

## 副作用、幂等与重试

按钮防抖和限流只能减少请求，不能保证幂等。对创建、扣减、设备控制等有副作用的关键操作，按其风险定义：

1. 幂等键的生成方、操作/租户/主体作用域、有效窗口及持久化要求；同一个逻辑操作重试应复用同一键
2. 同键同载荷的结果重放或处理中响应；同键不同载荷的冲突行为；不同键触发同一业务动作时是否还有业务唯一约束
3. 并发去重与业务写入的原子边界。简单“查一下没有再写”存在竞态；说明唯一约束、事务或等效机制如何覆盖崩溃窗口
4. 去重记录、业务结果和外部系统不在同一事务时的失败窗口。按需要选用事务性发件箱、下游幂等键、状态查询/对账、补偿或人工处理，不宣称跨边界天然恰好一次
5. 下游超时可能“已成功但未收到响应”，不能无条件换新键重试。先说明可查询性、重试安全性及未知结果的恢复方式

只对明确可安全重试的错误设置重试，限制次数与总时长，采用适当退避/抖动并遵守服务端限速提示。永久失败、参数错误和明确无权不靠重试解决；达到上限应进入可观察的失败/待处理状态。消息重复与乱序按业务需要处理，不能只画“入队 → 成功”。

## 并发、生命周期与失败恢复

- 明确共享状态的所有者、读写边界和冲突处理。桌面/设备场景关注线程亲和性、取消传播、连接断开、服务启动/关闭和资源释放，不能只写服务端事务
- 成功状态区分“已接受、处理中、已完成”，定义进度/失败通知与重新打开后的恢复；内存中运行状态不要误当作持久成功记录
- 关键状态迁移应包含适用的重复、超时、取消、崩溃恢复和非法状态处理。只对真实存在的状态建模，不增加无业务价值的状态机
- 文件替换/备份、数据库迁移或设备配置变更要说明验证、原子性边界、恢复所需信息与兼容窗口。回滚可能丢新数据或不可逆时直说，不能承诺“失败就回滚”而不分析条件
- 外部依赖列出已知契约、限额、可用性与未验证假设；对不可控依赖给联调/故障验证任务，不编造供应商性能结论

## 验证与运维边界

按风险选择契约测试、集成测试、并发/重复/故障注入、迁移演练或容量测试。性能验证注明数据量、工作负载、硬件、测量窗口和目标分位数，无法执行时明确后续验证门槛。

只设计当前阶段需要的可观测性：能区分失败原因、关联一次操作并定位关键依赖；日志避免敏感数据。需要备份/恢复的系统说明恢复目标是否为需求或建议，并通过演练验证，不因“有备份”就声称满足恢复要求。

说明发布/兼容策略时，文档本身不授权部署、删数据、变更权限或运行迁移；执行属于独立的实现与操作范围。
